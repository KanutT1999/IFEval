**This gap is confounded with** (we changed all of these at once): (1) different model family/weights, (2) scale (0.5–3B vs GPT-4 / PaLM 2 S, sizes undisclosed), (3) precision and hardware (fp16 on one local GPU vs. provider serving), (4) prompt template (each model's own chat template incl. any injected default system prompt, vs. API-side formatting), (5) decoding (greedy, 1280-token cap vs. unstated API settings), plus (6) time: the paper's responses were scraped in 2023 and the item list has since been edited (key 2785, June 2024; see scorer_validation.md). None of these can be attributed to size alone.
